Reading it

  • RAM is flat per type the entire run: broker / compute / registry hold ~0.040 GB per node, admin-ui ~0.05–0.06. No type creeps up over 30 min → no per-type memory leak.
  • CPU stays low and well under budget per type (broker budget 4.0c, gateway/registry 2.0c, compute 1.0c, admin-ui 2.0c). Gateways run a touch hotter (write-sim traffic), admin-ui rises with fleet size (it renders/aggregates more), both bounded.
  • Counts grow because the soak harness re-spawned 5 nodes / 5 min while chaos's effective kill rate was lower (it picks from a spawn registry that accumulates already-dead names, so some picks are no-ops). Kills themselves work — verified: a manual kill removes the node + its process immediately, and processes==topology throughout (no ghosts).
