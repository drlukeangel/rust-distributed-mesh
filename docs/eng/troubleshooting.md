# Troubleshooting

When RDM refuses a call, rejects a frame or command, or returns an `Unknown` verdict, it emits a named span from the [span catalogue](../reference/rdm/spans.md). Each table below groups those spans by subsystem and gives the span name, the emitting code site, what the refusal or rejection means, and the architecture page to read next.
