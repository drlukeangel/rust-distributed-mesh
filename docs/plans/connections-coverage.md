# Connections coverage: every requirement and the cell that proves it

Issue [#3228](https://github.com/drlukeangel/rafka-v2/issues/3228). One row per requirement or scenario of
[connections.md](../architecture/connections.md) (§13 A-L, §15 1-24 and the §1-§12 statements they lean on),
[node.connections.admit](../architecture/lifecycles/node-connections-admit.md),
[node.connections.delete](../architecture/lifecycles/node-connections-delete.md), the connection rows of
[node-rpc-envelope.md](../architecture/node-rpc-envelope.md), and Q205, Q206, Q210 and Q212 as landed.

How to read a row:

- **page:line** is the statement's line in `docs/architecture/` at this commit.
- **cells**: each cell as `file:line`, then its `scripts/cells.sh` arguments (`cells.sh <crate> <executable> --
  <filter>`), then its tier. A cell is listed only where its body asserts the row's fact; a cell that only
  names a requirement is not listed.
- **tier**: `fast` runs in `scripts/rdm-gate-at.sh <path> fast` (every crate's test executable, the
  `rdm-test` scenario stems, the job `i143-2938-process`); `release` is a stem in that script's
  `RELEASE_ONLY` list (here only `connections_restart`).
- **none** means nothing proves it; the reason is given, and the "Page and code differ" section names
  every row where the code does not state what the page states.

Rows marked **(new)** are the cells this unit added; the "Added cells" section says which were RED first.
