# Test name census (rafka-v2 #3208)

Every RDM test under `crates/` and `tools/` checked against `docs/eng/testing-naming-conventions.md` (landed 23bb09f97), re-run after the renames of #3208. Produced by a script over every `#[test]` and `#[tokio::test]` attribute (including the cells the `cells!`, `successor_cells!` and `rows!` macros generate), file and line being the `fn` line (the macro invocation line for a macro cell). The first run's 134 cells and 9 files are each renamed below or kept with the reason its word is another sense.

## Totals

- Tests checked: 2304 (907 unit cells in `src/`, 1397 in `tests/`); every binary's count is the first run's plus the cells landed since, none lost to a rename.
- First run: 134 cells and 9 file names with a finding. Renamed: 50 cells and 7 files. Kept, each with its reason below: 84 cells and 2 files.
- Kept findings by rule: 1.2: 30; 1.3: 56; file names (Rule 2.5): 2. Rules 1.1 and 2.4: none left.
- Rule 1.4 ("Most RDM cells carry a `/// CONTRACT:`"): 1505 cells have `CONTRACT` in the comment block directly above them; the doc states "most", so the rest are not findings.
- Rules 2.1, 3.2 and the file-structure rules as in the first run; no new module name is another module's suffix (Rule 3.2).

## What was and was not checked

- Rule 1.1 is a sentence rule; only its checkable floor is tabled: a name of fewer than four words, or one ending `_works`, `_test`, `_basic`, `_smoke` or `_sanity`.
- Rule 1.3 uses CLAUDE.md's full ban list (the name check's `RETIRED` set plus `epoch`, `holder`, `tree`, `partition`, `resolver`, `cut-off`, `held-running`, `hung hold`, `committed seat`, `exit proof`, `proven exit`, `child mesh`, `leadership view`), on whole `_`-separated words. Rule 1.2 is applied literally.
- A renamed cell keeps its body and assertions; a renamed name holds no `RETIRED` word (`python3 scripts/name-check.py origin/main HEAD` prints nothing). String literals in bodies are not names and are not matched: the estate owners' `subfeature` labels `"late-authority"`, `"cohort-election"` and `"role-cohort"`, and the status fold's temporary directory prefix `status-seat-fold-`, are unchanged.
